# Danbaizhi Agent Code README

## Overall approach

This image runs the protein conformation ensemble agent from `/app/run.sh`.
The entrypoint dispatches to `submit.tracks.danbaizhi.DanbaizhiRunner`, which
copies mounted JSON inputs into the project workspace, runs the project
prediction command, and packages generated conformation files.

## Runtime data and output

- Input: `/saisdata/` or a mounted subdirectory containing `1.json`, `2.json`,
  and `3.json`.
- Output: `/saisresult/submission.zip`.
- The project code first generates `Project/result/output.zip`; the track runner
  extracts that archive into the staging directory and the shared packer writes
  `/saisresult/submission.zip` for platform scoring.

Results must be generated by the agent during container execution. The image
must not contain fixed prediction zip files, hard-coded test answers, or hidden
precomputed conformation results.

## Code layout in image

- `/app/run.sh`: unique evaluation entrypoint.
- `/app/submit/`: runner, packer, and track dispatch code.
- `/app/Project/code/`: main protein prediction pipeline.
- `/app/Project/agent/`: agent configuration and prompt assets when present.
- `/app/Code/`: audit copy of inference code.
- `/app/Reference/`: audit notes and shared conventions.
- `/app/agent_code/README.md`: this reproduction README.

## Model and prediction workflow

The agent reads protein/task JSON files, prepares project input files, runs
`code/main.py predict`, and extracts the generated project output zip into the
submission staging directory. The project code records its run state and should
emit an audit log in the packaged output.

## Data processing

Mounted JSON files are copied at runtime into `/app/Project/data/`. No training
or validation dataset should be baked into the final image. The Docker build
excludes `Project/checkpoint/` and `Project/result/`; the default runtime also
disables golden checkpoint conformer copying. Any priors or knowledge files
included in the image must be generic method guidance, not target-specific
answer instructions or precomputed predictions.

## Environment

- Base image: Python 3.10 slim.
- Python packages: `numpy`, `mdtraj`, `openmm`.
- System build tools are installed only while required packages are installed
  and then removed.

## Reproduction

Inside the image:

```bash
FUSAI_TRACK=danbaizhi SAISDATA=/saisdata SAISRESULT=/saisresult sh /app/run.sh
```

Expected artifact:

```text
/saisresult/submission.zip
```

## External services and API keys

If an LLM-assisted variant is enabled, configure:

- `LLM_API_KEY`: API key location.
- `LLM_BASE_URL`: provider base URL.
- `LLM_PROVIDER`: provider name.

Do not hard-code personal secrets in source code.

## Runtime notes

The final image should include inference code and reproducibility notes, but not
training datasets, validation datasets, model checkpoints that violate the rules,
or precomputed prediction files.
